# ipc-surface.txt — the reviewed IPC contract (one process since P2.1: bar hosts settings).
#
# Checked by tools/check-ipc. Column 1 is target.function exactly as declared
# in any QML under bar/ or settings/ (the checker re-extracts those, so a
# handler that disappears fails the gate). Column 2 is the caller class:
#
#   bound    a Hyprland keybind in ~/.omni-nix/configs/hypr/keybindings.lua
#            dispatches it — the bind must exist (drift check) and parse
#   internal called from inside the repo (QML spawn strings); the checker
#            must find the call site
#   manual   CLI / external tools by design — exempt from caller search
#   unused   declared, no known caller — warns only; either wire it, delete
#            it, or reclassify
#
# A caller that names an undeclared target.function is ALWAYS a hard failure
# (the silent no-op keybind class) wherever it is found.
